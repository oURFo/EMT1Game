# EMT：黃金救援

繁體中文 2D 台灣 EMT-1 動態病患模擬遊戲。採**單案精練模式**：每次隨機一件派遣，玩家自行選擇觀察、儀器、問診、處置與送醫；病患生理狀態會隨時間與處置持續演變（含操作模組期間）。

> 本作僅供教育模擬，不取代正式 EMT 訓練、醫療指示或所在地勤務規範。

## 本機執行

```bash
npm install
npm run dev
```

## 品質檢查

```bash
npm run typecheck
npm test
npm run build
```

## GitHub Pages

1. 將專案推送至 GitHub，預設分支命名為 `main`。
2. 到儲存庫的 **Settings → Pages**，將 Source 設為 **GitHub Actions**。
3. 推送至 `main`，或從 Actions 手動執行 **Deploy to GitHub Pages**。

Vite 使用相對資源路徑，因此可部署於使用者網站或任意儲存庫子路徑。

## 內容

- **150** 個動態案例，分 **入門／進階／專科** 三級
- 完整分類工具箱：場景安全、目視與徒手評估、儀器量測、問診、處置、復甦與送醫
- 外觀、膚色、傷處與出血資訊需經觀察才能取得；血壓、血氧、體溫與血糖需使用儀器
- 讀值包含量測時間並會過期；出血、灌流、血氧、體溫、意識與生命徵象持續演算
- 互動技術模組：GCS、氧氣、BVM、呼吸道、出血控制、CPR／AED
- 送醫時可勾選客觀資料並撰寫危急原因；結案對照系統判定
- 未完成場景安全於結案大幅扣分並顯示警告
