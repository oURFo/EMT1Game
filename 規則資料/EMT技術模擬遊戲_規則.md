# EMT 技術模擬遊戲規則

## 產品定位

本專案是可部署於 GitHub Pages 的 2D 值班事件模擬遊戲。玩家依序完成派遣判讀、場景安全、初步評估、問診、EMT-1 處置與運送決策。內容僅供教育模擬，不替代正式訓練、醫療指示或所在地救護規範。

## 遊戲循環（單案精練）

1. 從主選單選擇案件分級（入門／進階／專科／全部）並開始值勤。
2. 系統隨機抽取 **1 件** 派遣。
3. 讀取派遣資訊後進入現場。
4. 玩家從完整工具箱自行選擇觀察、徒手評估、儀器、問診、處置、復甦與運送動作。
5. 病患資訊預設隱藏；時間每秒流逝，**操作模組期間病況仍持續演變**。
6. 儀器讀值會過期，需自行決定是否重新量測。
7. 送醫時勾選客觀依據並撰寫危急原因。
8. 結案顯示評分、安全警告、流程建議與危急判定對照。
9. 返回主選單；本機保存最佳成績與完成件數。

## 內容規則

- 案例資料庫 **150 件**，分三級難度。
- 不模擬藥物劑量、侵入性處置或超出 EMT-1 範圍的技術。
- 每案提供派遣、初始生理、建議／危險動作、結案解析。

## 評分規則

- 建議動作、GCS 準確度、病況穩定度與流程完整度加分。
- 危險或不適當行動扣分。
- **未執行場景安全（PPE／危害控制）於結案大幅扣分並顯示警告**。
- 分數最低為 0。
