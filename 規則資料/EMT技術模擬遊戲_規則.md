# EMT 技術模擬遊戲規則

## 產品定位

本專案是可部署於 GitHub Pages 的 2D 值班事件模擬遊戲。玩家依序完成派遣判讀、場景安全、初步評估、問診、EMT-1 處置與運送決策。內容僅供教育模擬，不替代正式訓練、醫療指示或所在地救護規範。

## MVP 遊戲循環

1. 從主選單選擇難度並開始班次。
2. 讀取派遣資訊後進入現場。
3. 玩家從完整工具箱自行選擇觀察、徒手評估、儀器、問診、處置、復甦與運送動作。
4. 病患資訊預設隱藏：外觀、膚色、傷處與出血須經觀察；血壓、血氧、體溫與血糖須使用對應儀器。
5. 每次行動消耗時間；出血、灌流、血氧、體溫、血糖、意識與生命徵象依時間及持續處置演算。
6. 儀器讀值記錄量測時間，超過時限會標記為過期，玩家須自行決定是否重新量測。
7. 每案包含地點、天氣、環境溫度、時間及現場危害，並影響評估優先順序。
8. 選擇送醫後取得安全、順序、時間與處置評分。
9. 完成三案後顯示班次總評並保存最佳成績。

## 內容規則

- 第一版包含教學與六案：外傷、呼吸困難、胸痛、疑似低血糖、熱傷害、疑似中風。
- 不模擬藥物劑量、侵入性處置或超出 EMT-1 範圍的技術。
- 每案必須提供派遣敘述、病患資料、初始生命徵象、可用行動、必要行動、危險行動與案後解析。
- 醫療判斷以遊戲內案例規則為準；任何歧義均以「先確保場景與生命安全」為優先。

## 評分規則

- 正確必要行動依重要性加分，首次完成才計分。
- 危險或不適當行動扣分，重複行動不重複得分。
- 過度延遲會造成病患穩定度下降並扣除時間分。
- 未完成關鍵安全步驟即送醫，結算時追加漏項扣分。
- 分數最低為 0；班次成績為各案分數合計。

## 驗收標準

- 桌機與手機瀏覽器可完成完整班次。
- 重新整理後可保留設定與最佳成績。
- 六個案例均能進入、結算並顯示解析。
- TypeScript 型別檢查、單元測試與正式建置全部通過。
- GitHub Pages 子路徑能正確載入靜態資源。
